Where to find the database and keys
  • On macOS, the database is usually at ~/Library/Application Support/Termark/backend/termark.db.
  • On Windows, installed builds use %AppData%\Termark\backend; portable builds use the app’s data folder.
  • The keychain service is termark.app. Entries are named local-data-key or portable-local-data-key.
