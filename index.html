Decrypted data

Choose a database or sync snapshot, enter its key, and decrypt to see the saved hosts and credentials here.

Where to find the database and keys
  • On macOS, the database is usually at ~/Library/Application Support/Termark/backend/termark.db.
  • On Windows, the installed build usually stores it in %AppData%\Termark\backend. The portable build uses the data folder beside the app.
  • The system keychain service is termark.app. The installed build uses local-data-key; the portable build caches portable-local-data-key.
